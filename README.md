# greekTrustFamily
King Shan is the emperor of Lengaburu and has been ruling the planet for the last 350 years. You can add more members to the family and know the family members

### To Build

``mvn clean install``

### To Run

Store the commands in a txt file.

``java -jar target/geektrust.jar <path_to_input_file>``

### How To Run Test

``mvn clean test``
